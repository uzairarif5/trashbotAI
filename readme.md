### TrashbotAI

This is my first time trying to implement a genetic algorithm. The neural network information is saved in the `shooter*/` folders in `shooterData/`. You can delete these folders if you want, and the program would create new neural networks of random weights and biases.

Also, I made this project back in 2022, and I wouldn't call the code here "clean". If I started this project again, I would have worked more on readability.

### How to use
Import this project in IntellJ and run homeScreen.java. If you want to play the game yourself, click "Self play", and if you want to see bots playing, click "Bot play".

If the `shooterData/` is empty, new `shooter*` folders will be created and the information about the neural network for each bot will be stored in these folders.

Once you start the bot play, you can use the left and right arrow keys to see the different bots.

Also, in the console, it shows the shooter scores after all the shooters lose.
